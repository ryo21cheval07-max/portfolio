Deadline Dungeon

締切リスクを可視化する、学生・就活生向けのタスク管理Webアプリです。レポート、ES、Webテスト、研究、面接準備など、複数の締切が重なりやすい学生生活を想定し、「今どのタスクが本当に危険か」を分かりやすくすることを目的に作成しました。

特徴

  • 締切までの日数、重要度、作業量、進捗率からリスクスコアを算出
  • 危険なタスクを「今日のボス」として優先表示
  • タスクをクエストや敵に見立て、進捗を進める体験として表現
  • localStorageを用いてブラウザ内にデータを保存

使用技術

Next.js / TypeScript / Tailwind CSS / Zustand / Zod / date-fns / Vitest / Vercel

工夫した点

単なるTodoアプリではなく、締切リスクを数値化し、ゲーム風のUIで表現することで、タスクへの着手ハードルを下げる体験を意識しました。また、リスクスコア計算ロジックを分離し、テストしやすい構成を意識しました。

状態

v0.1 MVPとして、主要な操作体験を実装しています。今後は、作業ログ、通知、クラウド同期、AIによるタスク分解提案などを改善したいと考えています。
